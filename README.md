# Credit_Card_Financial_Dashboard Using Power Bi
An Interactive Financial Dashboard built using Power Bi and SQL to analyze transaction and customer data, track KPIs and drive data-driven financial insights.

## 📌 Project Overview
This project involves the development of an interactive Credit Card Financial Dashboard using Power BI. It provides real-time insights into credit card transactions and customer demographics by connecting to a SQL database. The dashboard enables stakeholders to monitor key performance metrics, streamline data analysis, and make data-driven decisions.

## 🚀 Key Features
- **Interactive Dashboard:** Dynamic visuals for real-time monitoring of transactions and customer insights.
- **Data Integration:** Seamless connection with a SQL database for data extraction and processing.
- **Streamlined Analysis:** Efficient data processing to monitor trends, revenue, and key performance metrics.
- **Actionable Insights:** Structured reporting to support business decision-making processes.

## 🛠️ Tech Stack & Tools
- **Business Intelligence:** Power BI (Desktop & Service)
- **Database:** SQL / MySQL
- **Data Modeling:** DAX (Data Analysis Expressions)
- **ETL Process:** Power Query

## 📊 Core Metrics Tracked
- Total Revenue & Transaction Amount
- Customer Segmentation & Demographics (Age, Income, Job, etc.)
- Card Type Performance (Gold, Platinum, Silver, Blue)
- Quarterly & Monthly Financial Trends
- Delinquency & Interest Earned Rates
